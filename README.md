# ML-Hisaki-dark
The codes used in the paper (Explainable machine learning of the MCP dark count observed by Earth orbiting space telescope, https://doi.org/10.3389/fspas.2026.1786771) was uploaded in this page. The codes in the folder ("Savef") was used to save and create the dataset of Hisaki radaition and geometry (SaveHisaki_radaition.py), GOES-15 (SaveGOES_elec.py, mag.py, pronton.py, xray.py), and SYM-H (SaveSYM-H.py). Create_datatable.py in "Savef" combines those datasets into a single dataset and organizes them.

The other codes was used to execute the pre-processing, machine learning, and visualize the data.
